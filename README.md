# Breast Cancer Risk Analysis

Проект посвящён исследованию факторов риска рака молочной железы и построению моделей бинарной классификации для прогнозирования признака `cancer`.

В работе используются агрегированные данные: каждая строка описывает комбинацию категориальных признаков, а столбец `count` показывает количество наблюдений с такой комбинацией. Поэтому при анализе, обучении и оценке моделей используются веса наблюдений.

> Проект носит учебно-аналитический характер и не является медицинской диагностической системой.

## Что делает проект

- загружает и проверяет данные;
- анализирует пропуски, типы данных и уникальные значения;
- изучает распределение целевой переменной `cancer` с учётом веса `count`;
- строит визуализации по признакам и целевой переменной;
- оценивает связь категориальных признаков с `cancer` через Cramer's V;
- исключает потенциальную утечку данных через признак `invasive`;
- кодирует категориальные признаки с помощью One-Hot Encoding;
- обучает и сравнивает несколько моделей классификации;
- оценивает качество моделей через ROC-AUC, PR-AUC, Log Loss, Brier Score, confusion matrix, recall, precision и F1-score;
- анализирует пороги классификации, включая порог по Youden's J;
- строит калибровочные таблицы и графики.

## Используемые модели

В проекте используются разные подходы к классификации:

- Logistic Regression;
- Linear SVM;
- SGD Classifier;
- Ridge Classifier;
- Bernoulli Naive Bayes;
- Decision Tree;
- Random Forest;
- Extra Trees;
- Gradient Boosting;
- HistGradientBoosting;
- AdaBoost;
- нейронные сети на TensorFlow/Keras;
- дополнительные эксперименты с XGBoost и методами балансировки классов из `imbalanced-learn`.

## Данные

Основные столбцы набора данных:

| Столбец | Описание |
| --- | --- |
| `menopaus` | менопаузальный статус |
| `agegrp` | возрастная группа |
| `density` | плотность ткани молочной железы |
| `race` | расовая группа |
| `Hispanic` | принадлежность к Hispanic-группе |
| `bmi` | категория индекса массы тела |
| `agefirst` | возраст при первых родах / отсутствие родов |
| `nrelbc` | количество родственников первой степени с раком молочной железы |
| `brstproc` | наличие процедур на молочной железе в анамнезе |
| `lastmamm` | результат последней маммографии |
| `surgmeno` | хирургическая менопауза |
| `hrt` | гормональная терапия |
| `invasive` | признак инвазивного рака; исключается из признаков, чтобы избежать утечки данных |
| `cancer` | целевая переменная |
| `training` | разделение на обучающую и валидационную выборки |
| `count` | вес строки, количество наблюдений |

В коде используются две версии данных:

- `risk_decoded.csv` — данные с декодированными категориальными значениями;
- `risk.txt` — исходный файл без заголовков, где значения представлены числовыми кодами.

## Результаты

В ходе выполнения проекта формируются:

- таблицы распределений признаков;
- графики распределения целевой переменной;
- stacked bar charts по признакам;
- heatmap-графики для сочетаний признаков;
- таблицы относительного риска;
- матрица Cramer's V;
- ROC-кривые и Precision-Recall-кривые;
- confusion matrix;
- таблицы сравнения моделей.

По результатам экспериментов лучшие классические модели показывают ROC-AUC примерно около `0.64`. При этом PR-AUC остаётся низким из-за сильного дисбаланса классов, поэтому в проекте отдельно анализируются веса, балансировка классов и разные пороги классификации.

## Особенности проекта

- `count` используется как вес наблюдений, потому что датасет агрегирован.
- `invasive` исключается из признаков модели, так как может привести к утечке информации о целевой переменной.
- Для категориальных признаков применяется One-Hot Encoding.
- Для несбалансированной классификации используются ROC-AUC, PR-AUC и анализ порогов.
- Часть моделей может обучаться дольше, особенно нейронные сети и ансамблевые методы.
